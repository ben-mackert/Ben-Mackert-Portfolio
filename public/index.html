PCB Design class · Fall 2026

Golden Arduino

My own version of an Arduino Uno, designed from scratch to be electrically quieter than the one you buy in a store. Any standard Arduino add-on board plugs into it.

It worked the first time I powered it on, with no fixes needed. Side by side with a store-bought Uno running the same test, it gave off about 7% as much electrical noise, and its chip’s supply dipped a third as much.
